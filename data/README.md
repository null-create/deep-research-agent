# Data Directory

Runtime and test data for the research assistant.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `benchmarks/` | Benchmark results (`.jsonl` files produced by `scripts/benchmark.py` / `run-bench.sh`) |
| `documents/` | Files downloaded and cached by the MCP file handler server (port 9191) |
| `prompt_data/` | Test queries used as benchmark inputs (e.g. `query.jsonl`) |
| `reports/` | Research reports generated by the agent |
